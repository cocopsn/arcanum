### Opciones

### Solución
```javascript
function comparar_versiones(casos, salidas_a, salidas_b) {
  const r = { fijo: { total: 0, a: 0, b: 0 }, reservado: { total: 0, a: 0, b: 0 } };
  for (const c of casos) {
    const g = r[c.conjunto];
    g.total += 1;
    if (Object.prototype.hasOwnProperty.call(salidas_a, c.id) && salidas_a[c.id] === c.esperado) g.a += 1;
    if (Object.prototype.hasOwnProperty.call(salidas_b, c.id) && salidas_b[c.id] === c.esperado) g.b += 1;
  }
  let lectura;
  if (r.reservado.b > r.reservado.a) lectura = "mejora";
  else if (r.reservado.b < r.reservado.a) lectura = "empeora";
  else if (r.fijo.b > r.fijo.a) lectura = "solo_conocidos";
  else lectura = "igual";
  return { fijo: r.fijo, reservado: r.reservado, lectura };
}
```

        g["total"] += 1
        if c["id"] in salidas_a and salidas_a[c["id"]] == c["esperado"]:
            g["a"] += 1
        if c["id"] in salidas_b and salidas_b[c["id"]] == c["esperado"]:

## Plan de evaluación de una nueva versión
type: production
id: plan-evaluacion
tiempo: 12

Escribe el plan para decidir si se promueve una nueva versión de la función de recuperación de P4-03 (el asistente que cita políticas): composición del conjunto fijo y del reservado (incluidos los tipos difíciles), evaluadores, criterio de promoción escrito antes de correr, qué reportas y qué haces si la versión mejora en el fijo pero no en el reservado.

### Modelo
- **Fijo (60 casos):** respondibles, sin evidencia, con contradicción por vigencia e inyecciones, todos con su tramo esperado o abstención; se usa para depurar y detectar regresiones.
- **Reservado (40 casos):** del mismo reparto de tipos, preparado por otra persona, que nadie del equipo mira al ajustar.
- **Evaluadores:** coincidencia de la decisión (responder o abstenerse); cobertura y precisión del tramo citado; ningún documento vencido; ninguna obediencia a la inyección.
- **Criterio de promoción:** la versión nueva no empeora en ningún tipo del fijo y mejora en al menos 3 casos del reservado sin empeorar en abstenciones ni inyecciones.
- **Reporte:** aciertos por versión y por conjunto, con tamaños; diferencias por tipo de caso.
- **Si sólo mejora en el fijo:** no se promueve; se reescribe el ajuste como criterio general y se vuelve a medir; el reservado se renueva si ya se usó varias veces.
### Regla
Una versión se promueve con un criterio escrito antes de correr, medido en un conjunto fijo (regresiones) y en uno reservado (generalización) con evaluadores que producen métricas, reportando tamaños; una mejora sólo en el fijo no es una mejora del producto.

- Lista evaluadores que producen métricas.
- Escribe el criterio de promoción antes de correr.
