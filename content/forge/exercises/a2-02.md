Banco ligero de la ruta A2. La misión: resolver dos problemas independientes con pruebas de borde bajo reloj, y explicar un

## Antes de leer: la ventana con set
type: prediccion
id: a2-02-pred-set
rol: prediccion

Esta función busca la subcadena más larga con a lo sumo k caracteres distintos:

```python
def mas_larga(s, k):
    izq, vistos, mejor = 0, set(), 0
    for der, ch in enumerate(s):
        vistos.add(ch)
        while len(vistos) > k:
            vistos.discard(s[izq]); izq += 1
        mejor = max(mejor, der - izq + 1)
    return mejor
```

¿Qué devuelve `mas_larga("abaccc", 2)`?

### Opciones
- 4, la respuesta correcta («accc»)
- [x] 5
- 3
- 6

### Justificación
Al llegar la primera c, el set es {a, b, c} y la función quita s[0] = 'a' aunque la a de la posición 2 sigue en la ventana.
El set queda {b, c} con una ventana «bac» de tres distintos, y desde ahí la ventana sólo crece: «bacc» y «baccc», largo 5. La
respuesta correcta es 4. El set no sabe cuántas copias de cada carácter hay dentro.

## La subcadena con k distintos
type: code
id: a2-02-code-k-distintos
tiempo: 15

Devuelve la longitud de la subcadena más larga de `s` con a lo sumo k caracteres distintos. Escribe primero tus pruebas de
borde: cadena vacía, k = 0, todos iguales y k mayor que los distintos.

### Especificación
Ventana [izq, der] con un diccionario de conteos. Al agregar s[der], suma 1 a su conteo. Mientras haya más de k llaves,
resta 1 al conteo de s[izq], borra la llave si llega a 0 y avanza izq. Después actualiza el mejor largo.

### Firma
```javascript
function masLargaConKDistintos(s, k) {
  // tu código
}
```
```python
def mas_larga_con_k_distintos(s, k):
    # tu código
    pass
```

### Casos
```json
[
  { "input": ["", 2], "expected": 0 },
  { "input": ["a", 0], "expected": 0 },
  { "input": ["a", 1], "expected": 1 },
  { "input": ["abaccc", 2], "expected": 4 },
  { "input": ["eceba", 2], "expected": 3 },
  { "input": ["aaaa", 1], "expected": 4 },
  { "input": ["abcabc", 3], "expected": 6 },
  { "input": ["abcabc", 5], "expected": 6 }
]
```

### Solución
```javascript
function masLargaConKDistintos(s, k) {
  const cuenta = new Map();
  let izq = 0;
  let mejor = 0;
  for (let der = 0; der < s.length; der++) {
    cuenta.set(s[der], (cuenta.get(s[der]) || 0) + 1);
    while (cuenta.size > k) {
      const c = s[izq++];
      const v = cuenta.get(c) - 1;
      if (v === 0) cuenta.delete(c);
      else cuenta.set(c, v);
    }
    mejor = Math.max(mejor, der - izq + 1);
  }
  return mejor;
}
```
```python
def mas_larga_con_k_distintos(s, k):
    cuenta = {}
    izq = mejor = 0
    for der, ch in enumerate(s):
        cuenta[ch] = cuenta.get(ch, 0) + 1
        while len(cuenta) > k:
            c = s[izq]
            izq += 1
            cuenta[c] -= 1
            if cuenta[c] == 0:
                del cuenta[c]
        mejor = max(mejor, der - izq + 1)
    return mejor
```

### Pistas
- Una llave se borra sólo cuando su conteo llega a 0.
- Con k = 0 la ventana siempre queda vacía y el mejor largo es 0.

## Duplicado cercano

### Especificación
Guarda para cada valor el último índice donde apareció. Al ver a[i], si el valor ya estaba y la distancia al último índice

### Firma
```javascript
function hayDuplicadoCercano(a, k) {
  // tu código
}
```
```python
def hay_duplicado_cercano(a, k):
    # tu código
    pass
```

### Casos
```json
[
  { "input": [[], 1], "expected": false },
  { "input": [[1, 2, 3, 1], 3], "expected": true },
  { "input": [[1, 2, 3, 1], 2], "expected": false },
  { "input": [[1, 0, 1, 1], 1], "expected": true },
  { "input": [[5, 5], 0], "expected": false },
  { "input": [[7], 10], "expected": false },
  { "input": [[1, 2, 1, 2, 1], 1], "expected": false }
]
```

### Solución
```javascript
function hayDuplicadoCercano(a, k) {
  const ultimo = new Map();
  for (let i = 0; i < a.length; i++) {
    if (ultimo.has(a[i]) && i - ultimo.get(a[i]) <= k) return true;
    ultimo.set(a[i], i);
  }
  return false;
}
```
```python
def hay_duplicado_cercano(a, k):
    ultimo = {}
    for i, x in enumerate(a):
        if x in ultimo and i - ultimo[x] <= k:
            return True
        ultimo[x] = i
    return False
```

### Pistas
- Basta el último índice: uno anterior está más lejos.
- k = 0 nunca puede cumplirse con i < j.

## Pruebas de borde mínimas
type: multiple_choice
id: a2-02-mc-bordes
rol: recuperacion

Sin volver al libro: tienes 3 minutos para escribir pruebas antes de codificar una ventana sobre un arreglo de enteros. ¿Qué
conjunto eliges?

### Opciones
- Tres casos grandes aleatorios, porque cubren más combinaciones.
- [x] Vacío, un elemento, todos iguales, el caso del enunciado y uno con negativos o ceros.
- Sólo el ejemplo del enunciado, porque es el que el juez seguro prueba.
- Un caso con el tamaño máximo, para medir el tiempo.

### Justificación
Los errores de ventanas viven en los bordes: índices que no avanzan con un arreglo vacío, ventanas que no se cierran con un
solo elemento, conteos que no se borran con repetidos y monotonía que se rompe con negativos. Los casos aleatorios grandes no
dicen qué esperar sin una referencia, el ejemplo del enunciado casi nunca toca los bordes y el tamaño máximo mide tiempo, no
correctitud.

## El enfoque descartado, por escrito
type: production
id: a2-02-prod-descartado

Escribe el registro de un enfoque inicial incorrecto de uno de los dos problemas: qué intentaste, en qué minuto, qué caso o
dato lo descartó y qué cambiaste.

### Modelo
Problema 1, minuto 4: ventana con set de caracteres, porque «a lo sumo k distintos» parecía pedir sólo saber cuáles hay.

- Da el caso o dato concreto que lo descartó, con el valor obtenido y el esperado.
- Explica el mecanismo del error y el cambio que lo corrige.
- Incluye los minutos reales.

function masLargaSinRepetir(s) {
