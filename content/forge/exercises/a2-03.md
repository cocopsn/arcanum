# A2-03 · Árboles y grafos cronometrados

Banco ligero de la ruta A2. La misión: resolver conectividad, dependencias y un problema de estado expandido bajo reloj, y
justificar visitados, complejidad y comportamiento en grafos desconectados. Los patrones están en OA-7 y OA-8.

## Antes de leer: marcar al sacar
type: prediccion
id: a2-03-pred-marcar
rol: prediccion

Un BFS sobre una cuadrícula de 1,000 × 1,000 sin muros marca cada celda como visitada cuando la **saca** de la cola, no
cuando la encola. ¿Qué pasa?

### Opciones
- No termina, porque las celdas se vuelven a encolar para siempre
- Da distancias incorrectas
- [x] Termina con las distancias correctas, pero una celda puede entrar a la cola varias veces (hasta una por vecino) y gasta más tiempo y memoria
- Cuesta exactamente lo mismo que marcar al encolar

### Justificación
Antes de que una celda salga de la cola, cada vecino que la descubre la vuelve a encolar, hasta cuatro veces en una
cuadrícula. La primera copia que sale lo hace en orden de distancia, así que la distancia registrada es correcta y las demás
se descartan al salir. El costo crece por un factor constante en tiempo y memoria, y en grafos densos el factor es el grado.
No hay ciclo infinito porque una celda ya sacada no se vuelve a procesar.

## Componentes con nodos aislados

### Casos

  { "input": [1, []], "expected": 1 },
  { "input": [3, []], "expected": 3 },
  { "input": [4, [[0, 1], [2, 3]]], "expected": 2 },

### Solución
```javascript
function contarComponentes(n, aristas) {
  const ady = Array.from({ length: n }, () => []);
  for (const [u, v] of aristas) {
    ady[u].push(v);
    ady[v].push(u);
  }
  const visto = new Array(n).fill(false);
  let comps = 0;
  for (let s = 0; s < n; s++) {
    if (visto[s]) continue;
    comps++;
    visto[s] = true;
    const cola = [s];
    for (let h = 0; h < cola.length; h++) {
      for (const v of ady[cola[h]]) {
        if (!visto[v]) {
          visto[v] = true;
          cola.push(v);
        }
      }
    }
  }
  return comps;
}
```
```python
from collections import deque

def contar_componentes(n, aristas):
    ady = [[] for _ in range(n)]
    for u, v in aristas:
        ady[u].append(v)
        ady[v].append(u)
    visto = [False] * n
    comps = 0
    for s in range(n):
        if visto[s]:
            continue
        comps += 1
        visto[s] = True
        cola = deque([s])
        while cola:
            u = cola.popleft()
            for v in ady[u]:
                if not visto[v]:
                    visto[v] = True
                    cola.append(v)
    return comps
```

### Pistas
- n = 0 no tiene componentes.
- Un lazo u–u no une a u con nadie más.

## Camino con muros que se pueden romper
type: code
id: a2-03-code-rupturas
tiempo: 20

Cuadrícula de cadenas con '.' libre y '#' muro. Sales de (0, 0) y llegas a (R − 1, C − 1), que siempre son libres. Te mueves

### Casos
```json
[
  { "input": [["."], 0], "expected": 0 },
  { "input": [["..", ".."], 0], "expected": 2 },
  { "input": [[".#", "#."], 0], "expected": -1 },
  { "input": [[".#", "#."], 1], "expected": 2 },
  { "input": [["...", "##.", "..."], 0], "expected": 4 },
  { "input": [[".##", "###", "##."], 2], "expected": -1 },
  { "input": [[".##", "###", "##."], 3], "expected": 4 },
  { "input": [["...##", "#..#."], 1], "expected": 5 },
  { "input": [["...##", "#..#."], 0], "expected": -1 }
]
```

### Solución
```javascript
function pasosConRupturas(grid, k) {
  const R = grid.length;
  const C = grid[0].length;
  const visto = new Set(["0,0," + k]);
  let frontera = [[0, 0, k]];
  for (let pasos = 0; frontera.length > 0; pasos++) {
    const siguiente = [];
    for (const [r, c, q] of frontera) {
      if (r === R - 1 && c === C - 1) return pasos;
      for (const [dr, dc] of [[1, 0], [-1, 0], [0, 1], [0, -1]]) {
        const nr = r + dr;
        const nc = c + dc;
        if (nr < 0 || nc < 0 || nr >= R || nc >= C) continue;
        const nq = grid[nr][nc] === "#" ? q - 1 : q;
        const clave = nr + "," + nc + "," + nq;
        if (nq < 0 || visto.has(clave)) continue;
        visto.add(clave);
        siguiente.push([nr, nc, nq]);
      }
    }
    frontera = siguiente;
  }
  return -1;
}
```
```python
from collections import deque

def pasos_con_rupturas(grid, k):
    R, C = len(grid), len(grid[0])
    visto = {(0, 0, k)}
    cola = deque([(0, 0, k, 0)])
    while cola:
        r, c, q, d = cola.popleft()
        if r == R - 1 and c == C - 1:
            return d
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < R and 0 <= nc < C:
                nq = q - 1 if grid[nr][nc] == "#" else q
                if nq >= 0 and (nr, nc, nq) not in visto:
                    visto.add((nr, nc, nq))
                    cola.append((nr, nc, nq, d + 1))
    return -1
```

### Pistas
- El caso ["...##", "#..#."] con k = 1 falla si los visitados son por celda.
- El número de nodos es R · C · (k + 1): ese es tu costo.

## Visitados con estado
type: multiple_choice
id: a2-03-mc-estado
rol: recuperacion

Sin volver al libro: un robot recorre una cuadrícula con una batería de 0 a 10 que se gasta al moverse y se recarga en
ciertas celdas. ¿Qué guardas como visitado en el BFS?

### Opciones
- La celda: una vez visitada, cualquier otra llegada es peor.
- [x] La pareja (celda, batería): llegar a la misma celda con más batería es otro nodo y puede abrir caminos que la primera llegada no abre.
- Nada: con batería no hay ciclos, así que no hace falta marcar.
- Sólo las celdas de recarga.

### Justificación
El nodo del grafo es el estado completo: posición más lo que el problema recuerda. Una llegada temprana con poca batería no
domina a una tardía con más batería, así que descartar por celda puede perder la única solución. Sin visitados, el robot
puede dar vueltas recargando sin fin. Marcar sólo recargas no evita revisitar el resto. El costo pasa a O(R · C · 11).

## Visitados, costo y desconexión, por escrito
type: production
id: a2-03-prod-defensa

Defiende, en cinco a siete líneas, tu solución de componentes: cuándo marcas visitados, cuánto cuesta y qué pasa con un grafo
desconectado o con nodos aislados.

### Modelo
Marco cada nodo al encolarlo, así entra a la cola una sola vez y nunca hay copias pendientes. Cada nodo se encola y se saca
una vez, y cada arista se revisa una vez por extremo, así que el costo es O(V + E) y la memoria O(V + E) por la lista de
adyacencia. Un BFS sólo alcanza su componente; por eso recorro todos los nodos y lanzo un BFS desde cada uno no visitado.
El número de lanzamientos es el número de componentes, y un nodo aislado cuenta como una. Repetidos y lazos no cambian el
resultado: el nodo ya está marcado.

### Regla
La defensa de un recorrido nombra cuándo se marca, por qué cada nodo y arista se procesa una vez y qué se hace con lo que el
primer recorrido no alcanza.

### Rúbrica
- Dice que marca al encolar y por qué.
- Da O(V + E) contando nodos y aristas.
- Explica el lanzamiento desde cada nodo no visitado y los aislados.
