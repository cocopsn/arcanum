## Antes de leer: veinte tareas
type: prediccion
id: a2-01-pred-n20
rol: prediccion

Un enunciado dice: «hay a lo sumo 20 tareas; elige el subconjunto de mayor valor que respete estas cinco reglas de
compatibilidad». ¿Qué te dice primero la restricción n ≤ 20?

### Opciones
- Que hace falta una programación dinámica lineal, porque probar subconjuntos nunca cabe
- [x] Que probar los 2^20 ≈ 10^6 subconjuntos cabe en tiempo, así que la fuerza bruta es una hipótesis válida
- Que el problema es de ordenamiento, porque 20 es poco
- Que hace falta un hash, porque hay que buscar compatibilidades

### Justificación
2^20 es cerca de un millón; revisar las cinco reglas en cada subconjunto son unos pocos millones de operaciones, muy dentro
de cualquier presupuesto. Un límite tan pequeño suele ser la forma en que el autor autoriza lo exponencial. La programación
dinámica puede existir, pero no es lo primero que pide la restricción, y ordenar o usar un hash no exploran subconjuntos.

## Tramos con suma cero
type: code
id: a2-01-code-suma-cero
tiempo: 12

Cuenta los tramos contiguos de `a` cuya suma es exactamente 0. Los valores pueden ser negativos y n llega a 10^5, así que la
solución cuadrática no cabe.

### Especificación
Recorre acumulando la suma de prefijos. Dos prefijos iguales delimitan un tramo de suma 0. Guarda en un diccionario cuántas
veces apareció cada suma, empezando con la suma 0 una vez, y suma esas apariciones al avanzar.

### Firma
```javascript
function contarSumaCero(a) {
  // tu código
}
```
```python
def contar_suma_cero(a):
    # tu código
    pass
```

### Casos
```json
[
  { "input": [[]], "expected": 0 },
  { "input": [[0]], "expected": 1 },
  { "input": [[1, -1]], "expected": 1 },
  { "input": [[1, 2, 3]], "expected": 0 },
  { "input": [[0, 0, 0]], "expected": 6 },
  { "input": [[3, -3, 3, -3]], "expected": 4 },
  { "input": [[2, -2, 1, -1, 0]], "expected": 6 }
]
```

### Solución
```javascript
function contarSumaCero(a) {
  const vistos = new Map([[0, 1]]);
  let suma = 0;
  let total = 0;
  for (const x of a) {
    suma += x;
    const c = vistos.get(suma) || 0;
    total += c;
    vistos.set(suma, c + 1);
  }
  return total;
}
```
```python
def contar_suma_cero(a):
    vistos = {0: 1}
    suma = total = 0
    for x in a:
        suma += x
        c = vistos.get(suma, 0)
        total += c
        vistos[suma] = c + 1
    return total
```

### Pistas
- La suma de a[i..j] es prefijo(j + 1) − prefijo(i): es 0 cuando los dos prefijos son iguales.
- Empezar con {0: 1} cuenta los tramos que arrancan en la posición 0.

## Negativos en un tramo contiguo
type: multiple_choice
id: a2-01-mc-negativos
rol: recuperacion

Sin volver al libro: un enunciado pide el tramo contiguo más corto con suma al menos S, y aclara que los valores pueden ser
negativos. ¿Qué haces con tu primera idea de ventana deslizante?

### Opciones
- La mantienes: la ventana deslizante resuelve todo problema de tramos contiguos.
- [x] La descartas o la revisas: con negativos, agregar un elemento puede bajar la suma y la ventana pierde la monotonía que justifica encogerla.
- La cambias por ordenar el arreglo, porque así desaparecen los negativos.
- La mantienes, pero recorriendo de derecha a izquierda.

### Justificación
La ventana deslizante funciona cuando agregar un elemento nunca empeora la condición y quitar uno nunca la mejora; con
valores no negativos, la suma sólo crece al extender. Los negativos rompen esa propiedad y encoger la ventana puede saltarse
la respuesta. Ordenar destruye la contigüidad que pide el problema, y recorrer al revés no cambia nada. Con negativos se
recurre a prefijos con otra estructura (por ejemplo, una cola monótona sobre los prefijos).

## Registro de un intento
type: production
id: a2-01-prod-registro

Resuelve (en papel o en tu editor) uno de los enunciados del set mixto con cronómetro y escribe su registro: hipótesis
inicial con la frase que la sostiene, minuto de confirmación o descarte, error y dato que lo reveló, y tiempo total.

### Modelo
Problema: saldos diarios con negativos, contar tramos de suma cero. Hipótesis 1 (minuto 0): ventana deslizante, por
«tramos contiguos». Descartada al minuto 2: «pueden ser negativos» rompe la monotonía. Hipótesis 2 (minuto 2): prefijos con
hash, porque dos prefijos iguales delimitan un tramo de suma 0. Error (minuto 9): empecé el diccionario vacío y perdí los
tramos que arrancan en 0; lo reveló el caso [1, −1]. Tiempo total: 12 minutos.

### Regla
Un intento sirve como evidencia cuando registra la hipótesis con su señal, el momento en que cambió y el dato que la tumbó;
el resultado solo no dice qué mejorar.

### Rúbrica
- Nombra la hipótesis inicial y la frase del enunciado que la sostiene.
- Registra minutos reales de confirmación o descarte.
- Describe el error con el caso o dato que lo reveló.
- Da el tiempo total sin redondear a lo que «debió» tardar.
