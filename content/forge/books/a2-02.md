## Dos problemas, un reloj

Con dos problemas en, por ejemplo, 70 minutos, el error caro no es el algoritmo sino el reparto del tiempo. Una regla simple:
lee los dos enunciados completos antes de escribir (5 minutos), empieza por el que reconoces con más certeza y escribe sus
pruebas de borde **antes** del código. Las pruebas de borde de arrays y diccionarios casi siempre son las mismas: vacío, un
elemento, todos iguales, todos distintos, el límite de tamaño y, si hay números, negativos y cero. Los enunciados del
[índice comunitario de coding](https://github.com/perixtar/Tech-OA-Interview-Questions/blob/master/formats/coding.md) sirven
para ensayar ese reparto; es un índice de la comunidad, no un temario oficial.

## El enfoque descartado es evidencia

La defensa de esta celda pide contar un enfoque inicial **incorrecto** y el dato que lo descartó. No es una confesión: es la
prueba de que verificas. El patrón más común en ventanas es usar un conjunto donde hacía falta un conteo. El tutorial de
[estructuras de datos de Python](https://docs.python.org/3/tutorial/datastructures.html) separa los dos: un `set` responde
si algo está, y un diccionario puede guardar cuántas veces está. En una ventana, quitar un carácter del `set` cuando todavía
queda otra copia dentro de la ventana deja un estado falso, y la respuesta sale demasiado grande sin ningún error.

## Ejemplo trabajado

**Problema 1.** La subcadena más larga con a lo sumo `k` caracteres distintos. Pruebas de borde primero: `("", 2) → 0`,
`("a", 0) → 0`, `("aaaa", 1) → 4`, `("abcabc", 5) → 6`. Solución: ventana con un diccionario de conteos; se encoge mientras
haya más de `k` llaves y una llave se borra sólo cuando su conteo llega a 0.

**Problema 2.** ¿Hay dos posiciones `i < j` con el mismo valor y `j − i ≤ k`? Diccionario de valor a último índice visto,
una pasada. Bordes: `k = 0` siempre da falso; un solo elemento, falso.

**Registro del enfoque descartado (problema 1):** «Minuto 4: ventana con `set`. Minuto 11: el caso `("abaccc", 2)` dio 5 y
debía dar 4. Al encoger quité la primera `a` del set con otra `a` todavía en la ventana. Cambié a conteos.»

## Contraejemplo

```python
def mas_larga(s, k):                 # versión con set: incorrecta
    izq, vistos, mejor = 0, set(), 0
    for der, ch in enumerate(s):
        vistos.add(ch)
        while len(vistos) > k:
            vistos.discard(s[izq]); izq += 1
        mejor = max(mejor, der - izq + 1)
    return mejor
```

Con `("abaccc", 2)` la ventana llega a `"bac"`, con tres distintos, mientras el set dice `{b, c}`, y termina reportando 5.
La respuesta es 4 (`"accc"`). Ninguna prueba con caracteres sin repetir dentro de la ventana lo detecta.

## Diagrama

```text
 s = a b a c c c      k = 2
     [a b a]          conteos {a:2, b:1}          largo 3

         [a c c c]    con conteos: {a:1, c:3}     largo 4  ← respuesta
 reloj: 5' leer ambos · pruebas de borde · 1er problema · 2º · repaso
```
